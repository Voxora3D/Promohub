# PromoHub — demo awal

## Cara menjalankan
1. Ekstrak ZIP ini.
2. Buka `index.html` di browser, atau gunakan editor seperti VS Code dan ekstensi Live Server.
3. Ganti enam proyek contoh di `script.js` dengan proyek nyata yang telah mendapat izin pemiliknya.
4. Ganti semua URL `https://example.com` dengan tautan proyek yang sudah diverifikasi.

## Fitur yang sudah ada
- Desain responsif untuk HP dan desktop.
- Pencarian proyek.
- Filter kategori.
- Urutkan nama A–Z atau pilihan.
- Kartu dan dialog detail proyek.
- Formulir pengajuan dengan validasi HTTPS.
- Ekspor pengajuan menjadi file TXT dan salin teksnya.
- Bagian cara kerja dan ajakan mempromosikan proyek.

## Batasan penting
Ini adalah prototipe front-end statis. Pengajuan tidak otomatis dikirim atau disimpan ke server; file TXT harus dikirim manual kepada pengelola. Daftar produk berada di `script.js`. Untuk situs publik sungguhan, tambahkan backend/database, proses moderasi, dan pengiriman formulir yang aman. Data produk saat ini adalah konten demo dan tidak boleh dianggap sebagai rekomendasi proyek nyata.
